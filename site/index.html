Console de l'animateur

Menez une soirée de quiz depuis votre ordinateur, avec un écran projeté pour la salle. L'application pilote le buzzer par Bluetooth.

Télécharger pour Windows

Version 1.4.0 · environ 18 Mo · Windows 10 ou 11, 64 bits

Ce qu'elle fait

  • Conduit la partie : question posée, buzz, bonne ou mauvaise réponse, scores, chrono. Le clavier du buzzer se verrouille pendant ce temps.
  • Affiche un écran public dans une fenêtre séparée, à glisser sur le projecteur et à passer en plein écran. Ce que la salle voit dépend du jeu, et la réponse n'y apparaît jamais avant la fin de la question.
  • Joue les sons par les haut-parleurs de l'ordinateur plutôt que par le petit haut-parleur du buzzer, et retombe sur ce dernier si le lien Bluetooth tombe.
  • Apporte 4014 questions rangées par thématique et cotées par difficulté et par tranche d'âge. Vous choisissez vos critères avant chaque manche et l'application la compose sur le champ. Vous pouvez aussi écrire vos propres questionnaires.

Installation

  • Décompressez l'archive où vous voulez, puis lancez buzzer_companion.exe. Il n'y a rien à installer.
  • Gardez les fichiers ensemble : l'exécutable a besoin des bibliothèques et du dossier data qui l'accompagnent.
  • Windows peut afficher un avertissement au premier lancement, faute de signature de code. « Informations complémentaires », puis « Exécuter quand même ».

Il vous faut aussi

  • Le buzzer à quatre boutons, avec son module Bluetooth.
  • Un ordinateur Windows avec Bluetooth basse énergie.
  • Un second écran ou un projecteur, si vous voulez l'écran public.
La banque de questions est téléchargée par l'application depuis ce même site. Toutes les questions se relisent sur une page : la revue des questions. Le code est ouvert : papatalon/Arduino-Buzzer.
