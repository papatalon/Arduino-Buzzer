# LES THÉMATIQUES SONT ÉCRITES, PAS DÉDUITES. Elles l'étaient, par mots-clés,
# et se trompaient sans le dire : « neige » rangeait Blanche-Neige dans Sports
# d'hiver, « dents » rangeait Les Dents de la mer dans Le corps humain. Une
# thématique est un jugement sur le sujet de la question, du même ordre que sa
# catégorie, et la catégorie n'a jamais été devinée.
#
# LES ONZE CATÉGORIES SONT AUSSI DES THÉMATIQUES, sous le nom du fichier :
# bouffe-et-cuisine, cinema-et-tele, culture-generale, culture-pop,

# sports. Elles ne s'écrivent PAS sous les questions de leur propre fichier,
# qui y sont déjà par leur catégorie ; on ne les écrit que sur une question
# d'un AUTRE fichier qui parle du même sujet, comme « @ quebec » sous une
# question québécoise rangée dans Culture pop.

# corps-humain, super-heros, creatures, sports-hiver, regne-vegetal, mer,
# transports, disney, nostalgie, voyages. Un slug inconnu arrête la
# génération.

# <fichier> <bloc> <rangs> » écrit les marqueurs au bon endroit.
